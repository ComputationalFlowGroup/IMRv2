# Bubble-wall boundary conditions

## Thermal-only wall (`f_wall_theta_exact`, nested in `f_imr_fd.m`)
Without mass transfer the wall heat flux balance `c1*Tw + c2*theta_w + K = 0`, with `Tw = (ag - 1 + u)/ag` and `theta_w = (u^2 - 1)/(2*ag)`, `u = sqrt(1 + 2*ag*theta_w)`, is exactly quadratic in `u`: `c2*u^2 + 2*c1*u + q = 0`, `q = 2*c1*(ag - 1) - c2 + 2*ag*K`. Both roots are formed in cancellation-free form, roots with `u < 0` are discarded (`u` is a square root), and if two remain the one whose `theta_w` is closest to the previous wall value is kept; the sign of `c2` depends on the grid spacing and the conductivity ratio, so no branch is hard-coded. `c2 = 0` is handled as the linear case `u = -q/(2*c1)`. If the discriminant is negative or no admissible root exists, the solver falls back to `fzero` on the residual. The Jacobian uses `d(theta_w)/dK = -u/(c2*u + c1)`, valid for either root.

## `f_wall_mass_bc.m`
With vapor mass transfer the balance adds the latent heat flux, which depends on the saturated wall vapor concentration `kvw(Tw, P)` through `Pv(Tw) = C1*exp(C2/Tw)`. The balance is transcendental in `Tw` (the unknown appears both algebraically and inside the exponential), so it has no closed-form root. `f_wall_mass_bc(v, c)` returns the residual and its gradient with respect to `v = [theta_w, Tm(2), Tm(3), theta(end-1), theta(end-2), kv(end), kv(end-1), kv(end-2), P]`. `f_imr_fd` solves it by a warm-started Newton iteration (typically 3–4 iterations), falling back to `fzero` only if Newton does not converge; `f_jacobian_fd` uses the gradient for the implicit derivative of `theta_w`.
