# Bubble-wall boundary conditions

This page covers the wall temperature solve in `f_imr_nodal`: the nested `f_wall_theta_exact` without mass transfer, and the file `f_wall_mass_bc.m` with mass transfer.

## Thermal-only wall (`f_wall_theta_exact`, nested in `f_imr_nodal.m`)
Without mass transfer the wall heat flux balance `c1*Tw + c2*theta_w + K = 0`, where `K` collects the other nodes of the wall rows, with `Tw = (ag - 1 + u)/ag` and `theta_w = (u^2 - 1)/(2*ag)`, `u = sqrt(1 + 2*ag*theta_w)`, is exactly quadratic in `u`: `c2*u^2 + 2*c1*u + q = 0`, `q = 2*c1*(ag - 1) - c2 + 2*ag*K`. Both roots are formed in cancellation-free form, roots with `u < 0` are discarded (`u` is a square root), and if two remain the one whose `theta_w` is closest to the previous wall value is kept; the sign of `c2` depends on the grid spacing and the conductivity ratio, so no branch is hard-coded. `c2 = 0` is handled as the linear case `u = -q/(2*c1)`. If the discriminant is negative or no admissible root exists, the solver falls back to `fzero` on the residual. If that also fails, which happens only for unphysical trial states of the integrator, it returns the least-residual point of the quadratic and continues, so that the integrator rejects the step on its error estimate instead of the run stopping. The Jacobian uses `d(theta_w)/dK = -u/(c2*u + c1)`, valid for either root.

## Wall closure with mass transfer (`f_wall_mass_closure`, nested in `f_imr_nodal.m`)
With vapor mass transfer the balance adds the latent heat flux, which depends on the saturated wall vapor mass fraction through `Pv(Tw) = C1_pv*exp(C2_pv/Tw)` (`C2_pv < 0`). The balance is transcendental, so it has no closed-form root. The closure solves it for the wall vapor mass fraction `kv_w`, which is confined to `(0, 1)`, rather than for `theta_w`, which has no natural bounds.

For a trial `kv_w`, `f_wall_mass_residual` evaluates, in order:
1. the vapor partial pressure `ps = P*kv_w*Rvg/(kv_w*Rvg + 1 - kv_w)`;
2. the wall temperature from inverting the saturation relation, `Tw = C2_pv/log(ps/C1_pv)`, with the solver's own constants (consistent with `f_pvsat`);
3. the wall Kirchhoff temperature by the forward transform, `theta_w = 0.5*alpha_m*(Tw^2 - 1) + beta_m*(Tw - 1)`;
4. the flux balance multiplied through by `D = (kv_w*Rva + Rg)*Tw*(1 - kv_w)`, which is positive on the bracket:
   `r = D*(grad_Tm(1)*Tw + grad_Tr(1)*theta_w + flux_fixed) + P*(grad_C(1)*kv_w + carrier_fixed)`.
   This has the same root as the balance of `f_wall_mass_bc` and no reciprocal that vanishes as `kv_w -> 1`.

**Hoisted per call.** The contributions of the other nodes of the wall rows do not depend on `kv_w`, so they are computed once: `flux_fixed = grad_Tm(2:end)*Tm(iwall_m) + grad_Tr(2:end)*theta(iwall_b)` and `carrier_fixed = grad_C(2:end)*kv(iwall_b)`. The order matters: `Tm(iwall_m)` runs outward from the wall (`Tm(2:3)` for finite differences), while `theta(iwall_b)` and `kv(iwall_b)` run inward (`theta(end-1:-1:end-2)` and `kv(end-1:-1:end-2)`), matching the coefficient order.

**Mixture coefficients.** `alpha_m = kv*alpha_v + (1 - kv)*alpha_g` uses the stored wall value `kv(end)`, not the trial `kv_w`, as the solver always has. Because the right-hand side sets `kvdot(end) = 0`, the stored value never changes during a run: it is the initial `kv0`, not a one-step lag. This is kept deliberately and should be revisited separately. The transform normalizes the conductivity to 1 at `T = 1`, `K = alpha_m*T + beta_m` with `beta_m = 1 - alpha_m`. That makes the forward transform the exact inverse of the `sqrt` form used elsewhere, `T = (alpha_m - 1 + sqrt(1 + 2*alpha_m*theta))/alpha_m`. The input coefficients do not satisfy this normalization exactly (`alpha_g + beta_g = 1.0024`, `alpha_v + beta_v = 0.9976` in the default case), and the thermal equation's conductivity uses them as given; that small inconsistency predates this closure.

**Solve.** The bracket is fixed at `kv_w` in `[1e-13, 1 - 1e-13]`; no initial guess is used. The residual is evaluated on 64 equally spaced points of the bracket, including both ends, in one vectorized call. If the ends have the same sign, the solver stops with an error that reports the time and state, since that indicates a physical or indexing problem rather than a solver problem. Otherwise the grid interval with the first sign change becomes the new bracket. Two such rounds narrow it by a factor of about `63^2 = 4e3`, about as much as 12 bisection steps. Three Newton steps with the analytic derivative `dr/d(kv_w)` follow, each kept inside the final interval. There is no adaptive termination, so every call costs the same: 2 vectorized evaluations of 64 points, 3 Newton evaluations and 1 final evaluation. Against 3 rounds of 32 points, this layout gives the same roots (round-off, 360 trajectory states) at 1.0 to 1.4 times less cost per call.

Over 360 states from mild and violent collapses, with `kv_w` between `0.0015` and `0.9992`, the root agrees with a tight solve of the `f_wall_mass_bc` balance to `4e-16` in `theta_w`. A call takes about 350 µs in GNU Octave, 2.1–2.4 times faster than 20 scalar bisection steps with central-difference Newton, and mass-transfer runs take 1.2–1.6 times less time.

**Wall state.** The converged `kv_w` gives `theta_w`, which is assigned to `theta(end)`. `T` is then computed from `theta` with the stored `kv(end)`, so that `T(end)` uses the same mixture coefficient as the closure, and only then is `kv(end)` set to the converged `kv_w`. The bubble pressure, velocity, conductivity and vapor equations all see the converged wall value.

## `f_wall_mass_bc.m`
`f_wall_mass_bc(v, c)` evaluates the same balance in terms of `theta_w`, with its gradient with respect to `v = [theta_w, Tm(iwall_m), theta(iwall_b), kv(end), kv(iwall_b), P]`. `iwall_m` and `iwall_b` hold two nodes each for finite differences and every node for Chebyshev. `f_jacobian_nodal` uses the gradient at the converged root for the implicit derivative `d(theta_w)/dx = -(dr/dx)/(dr/d(theta_w))`. Scaling a residual by a positive factor does not change that ratio at a root, so the derivative is the one of the closure's residual as well.
