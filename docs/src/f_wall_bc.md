# Bubble-wall boundary conditions

This page covers the wall temperature solve in `f_imr_nodal`: the nested `f_wall_theta_exact` without mass transfer, and the file `f_wall_mass_bc.m` with mass transfer.

## Thermal-only wall (`f_wall_theta_exact`, nested in `f_imr_nodal.m`)
Without mass transfer the wall heat flux balance `c1*Tw + c2*theta_w + K = 0`, where `K` collects the other nodes of the wall rows, with `Tw = (ag - 1 + u)/ag` and `theta_w = (u^2 - 1)/(2*ag)`, `u = sqrt(1 + 2*ag*theta_w)`, is exactly quadratic in `u`: `c2*u^2 + 2*c1*u + q = 0`, `q = 2*c1*(ag - 1) - c2 + 2*ag*K`. Both roots are formed in cancellation-free form, roots with `u < 0` are discarded (`u` is a square root), and if two remain the one whose `theta_w` is closest to the previous wall value is kept; the sign of `c2` depends on the grid spacing and the conductivity ratio, so no branch is hard-coded. `c2 = 0` is handled as the linear case `u = -q/(2*c1)`. If the discriminant is negative or no admissible root exists, the solver falls back to `fzero` on the residual. If that also fails, which happens only for unphysical trial states of the integrator, it returns the least-residual point of the quadratic and continues, so that the integrator rejects the step on its error estimate instead of the run stopping. The Jacobian uses `d(theta_w)/dK = -u/(c2*u + c1)`, valid for either root.

## `f_wall_mass_bc.m`
With vapor mass transfer the balance adds the latent heat flux, which depends on the saturated wall vapor concentration `kvw(Tw, P)` through `Pv(Tw) = C1*exp(C2/Tw)`. The balance is transcendental in `Tw` (the unknown appears both algebraically and inside the exponential), so it has no closed-form root. `f_wall_mass_bc(v, c)` returns the residual and its gradient with respect to `v = [theta_w, Tm(iwall_m), theta(iwall_b), kv(end), kv(iwall_b), P]`, where `iwall_m` and `iwall_b` are the other nodes of the wall rows of the first-derivative matrices: two each for finite differences (`Tm(2:3)`, `theta(end-1:-1:end-2)`), every node for Chebyshev. `f_imr_nodal` solves it in two stages; `f_jacobian_nodal` uses the gradient for the implicit derivative of `theta_w`.

1. **Warm-started Newton.** Starting from the previous wall value, up to 10 Newton steps; typically 3–4 are needed. The result is accepted if it converges inside the physical bracket below.
2. **Bracketed search.** Otherwise the wall vapor concentration must lie in `(0, 1)`. Inverting the saturation condition gives the wall temperature in closed form: `Pv(Tw) = P*kv*Rvg/(kv*Rvg + 1 - kv)`, so `Tw = C2/log(Pv/C1)`. `kv = 1e-13` and `1 - 1e-13` therefore give a bracket `[theta_lo, theta_hi]` on `theta_w`, since `Tw` and `theta_w` increase with `kv`. A safeguarded Newton–bisection search then runs on that bracket. A Newton step that leaves the bracket is replaced by bisection, so the search converges whenever the residual changes sign on the bracket. Only if it does not, `fzero` is the last resort.

In normal runs the first stage always succeeds, so results are unchanged. Forcing every solve through the second stage, from starting guesses off by +1 and -0.5, it converged every time without `fzero`, in 3–7 iterations on average and at most 52. The resulting `R(t)` matched the Newton runs to within the change caused by tightening the integrator tolerance from `1e-8` to `1e-9`.

The mixture conductivity at the wall uses the vapor concentration stored at the previous evaluation (`kv(end)`), a one-step lag kept from the original solver.
